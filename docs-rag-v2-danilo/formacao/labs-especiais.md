## O que são os Labs Especiais?

Os **Labs Especiais** são cenários práticos avulsos e aprofundados que simulam demandas reais de consultoria, arquiteturas corporativas e problemas complexos do dia a dia de empresas que utilizam a AWS. 

Essa biblioteca de laboratórios práticos é **dinâmica e continuamente expandida** pelo Henrylle Maia com novos desafios ao longo dos 2 anos de acesso do aluno à plataforma.

---

## Relação Completa dos Labs Especiais Disponíveis

1. **Amazon Aurora Serverless:** Implementação prática de banco relacional sob demanda com autoscaling automático de capacidade sem gerenciamento de nós.
2. **WordPress em Alta Disponibilidade:** Arquitetura multi-zona (Multi-AZ) com balanceamento de carga, banco RDS desacoplado e sistema de arquivos compartilhado Amazon EFS.
3. **WordPress em Alta Performance:** Otimização agressiva de tempo de resposta combinando cache em memória e distribuição global com CloudFront.
4. **VPC Peering Inter-VPC:** Conexão direta e roteamento seguro entre redes isoladas na AWS sem passar pela internet pública.
5. **CloudFront Functions na Prática:** Execução de código ultrarrápido na borda da CDN para redirecionamentos e manipulação dinâmica de cabeçalhos HTTP.
6. **Variáveis de Ambiente Seguras no Amazon ECS:** Como injetar senhas e chaves criptografadas diretamente do AWS Secrets Manager e SSM Parameter Store na inicialização de containers sem deixar valores expostos em texto claro nas Task Definitions.
7. **Bastion Host (Jump Box Seguro):** Configuração de servidor intermediário de salto para acesso a recursos em subnets estritamente privadas.
8. **Migrando Aplicações ECS entre Contas AWS Distintas:** Cenário corporativo de migração de serviços em containers entre ambientes (por exemplo: conta de desenvolvimento para conta de produção ou aquisição de empresas).
9. **Microsoft SQL Server com Docker na AWS:** Subindo banco SQL Server em container Linux na AWS, com rotinas de backup e restore de bancos de dados.
10. **Segurança Reforçada: AWS Systems Manager (SSM) com VPC Endpoints:** Acesso administrativo completo a servidores em subnets privadas sem Internet Gateway, sem IP público e sem tráfego pela internet.
11. **VS Code + BIA-DEV Remoto:** Montagem de ambiente de desenvolvimento remoto em instância EC2 conectado com segurança diretamente através do VS Code via SSH e SSM Session Manager.
12. **Cenário Prático de Segurança Tríplice:** Implementação combinando SSM Session Manager, VPC Endpoints e EC2 Instance Connect Endpoint para criar uma fortaleza de acesso administrativo blindada.
13. **Arquitetura x86 vs. ARM (Processadores AWS Graviton):** Comparativo prático de desempenho, compatibilidade de imagens Docker e redução de até 20% no custo de instâncias e tarefas Fargate ao migrar para a arquitetura Graviton (ARM64).
14. **Gerenciamento Avançado de Secrets:** Estratégias de rotação de senhas e auditoria de consumo de segredos com CloudTrail.

## Dúvidas Frequentes sobre os Labs Especiais (FAQ)

**Os Labs Especiais são obrigatórios para concluir o curso?**
Não são obrigatórios para a trilha principal, mas são altamente recomendados para quem deseja se destacar em processos seletivos e resolver problemas complexos do mercado.

**A lista de Labs Especiais recebe novos conteúdos?**
Sim! A biblioteca de Labs Especiais é atualizada com novos cenários e tendências da AWS ao longo dos seus 2 anos de acesso.

**O que o lab de arquitetura x86 vs ARM ensina?**
Ensina como compilar imagens de containers e escolher tipos de instância com processadores AWS Graviton (ARM64) para economizar até 20% em comparação com servidores Intel/AMD (x86).
